# Python Practice Projects 🐍

A collection of small, beginner-friendly games and practice programs built while working through ***The Big Book of Small Python Projects*** by Al Sweigart[cite: 1]. 

This repository serves as a personal portfolio tracking my progress through all 81 practical Python programming challenges[cite: 1].

---

## 🎮 Completed Games

| # | Game Name | File | Description |
|---|---|---|---|
| 01 | **Bagels** | `bagels.py` | A deductive logic guessing game where you try to guess a secret 3-digit number based on *Pico*, *Fermi*, and *Bagels* clues[cite: 1]. |
| 02 | **Birthday Paradox** | `birthday_paradox.py` | A Monte Carlo simulation that explores the surprising probability of shared birthdays in a group of people. |

---

## 🚀 How to Run a Game

Make sure you have Python installed on your system. You can run any game directly from your terminal or command line:

```bash
python bagels.py
# or
python birthday_paradox.py
